# LeadPulse Pro – AI Lead Generation SaaS Platform

LeadPulse Pro is a production-grade AI lead generation tool that automates finding, extracting, and managing business leads using Google Maps and AI enrichment.

## 🚀 Features (Day 1)
- Project architecture established
- Streamlit SaaS dashboard scaffold
- Google Cloud / Sheets integration structure
- Data persistence layer (ready)

## 🛠️ Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Add your `creds.json` (Google Service Account) to the root directory.
3. Run the app:
   ```bash
   streamlit run app.py
   ```
